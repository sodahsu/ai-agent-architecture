# 範例（Examples）

這個目錄中的所有範例都必須是**完全虛構、不可識別真實使用者，且適合永久公開**的內容。

建議使用這類泛化名稱：

- `example-repository`
- `example-agent`
- `example-skill`
- `example-workspace`
- `user@example.com`
- `<private-memory-store>`

禁止把下列真實資料複製到範例中：

- 本機設定
- Private Repository Metadata
- Production URL
- Log
- Screenshot
- Personal Memory
- 真實帳號、路徑或 Credential

範例的目的，是讓讀者不需要存取作者的真實環境，也能理解這套架構如何運作。

如果某個範例只有在知道作者的私人 Repository、公司、客戶或個人背景時才看得懂，就代表它還沒有完成去識別化。
