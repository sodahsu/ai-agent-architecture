# Examples

Examples in this directory must be synthetic and privacy-safe.

Use generic names such as:

- `example-repository`
- `example-agent`
- `example-skill`
- `example-workspace`
- `user@example.com`
- `<private-memory-store>`

Do not copy real local configuration, private repository metadata, production URLs, logs, screenshots, or personal memory into examples.

The purpose of examples is to demonstrate the architecture without requiring access to the author's actual environment.
